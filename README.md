# DVLD_System
The DVLD system is a comprehensive software solution (WinForms Application) designed to streamline and automate driver and vehicle licensing processes. It handles various functions including issuing new licenses, renewing or replacing existing ones, scheduling and managing driving tests, and processing applications for both domestic and international licenses. Built with a robust multi-tier architecture, it ensures secure data management, efficient workflow automation, and scalable service delivery for managing licensing operations.

## To run this project on Visual Studio you have to follow these steps:

### Step 1:
Restore the data base that exists in folder 'DataBase' with filename 'DVLD.bak'

### Step 2:
Open the solution using VS, it exists in folder 'DVLV' with filename 'DVLV.sln'

### Step 3:
Open the class with name 'clsDataAccessSettings' that exists in Data Access Layer (DAL) and set an appropriate  connection string.

### Step 4:
Run the project.
